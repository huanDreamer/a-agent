# web-chat（增量）

本次变更只改「对话里的提问卡片」这部分，其余行为不变。

## API

- `POST /api/chat/sessions/{id}/questions/{qid}/answer`
  - 请求：`{"selected": ["Postgres"], "text": "或者 MySQL"}`（两者至少有一个非空）
  - 200：`{"ok": true}`
  - 400：`selected` 不是卡片给出的选项 / 非多选却给了多个 / 不允许自定义却给了 text /
    两者都为空 —— 每种都有自己的说明
  - 404：问题不存在、不属于该会话、已超时、已被回答，或本轮已经结束
- SSE 事件 `ask_user`（见 agent-interaction）。

## 行为

- 卡片出现在**产生它的那一轮**里（实时：`text_delta` 之前；历史：该轮 assistant 消息的
  `tool_calls` 里），并且：
  - `pending`：选项可点（多选按多选语义）、自定义输入可用、提交按钮在"有答案"之前禁用；
  - 提交中：按钮禁用，失败时保留已填内容并显示原因；
  - `answered`：锁定选择，高亮被选中的项，显示自定义输入与「已提交」；
  - `timeout` / `cancelled`：锁定并说明"模型已自行继续"；
  - 历史（刷新后）渲染静态卡片，按落盘的工具参数与结果复原当时的选择。
- 非多选时：选择选项会清空自定义输入，输入自定义内容会清空选项 —— 单选语义下两者只能
  有一个是答案；多选时两者可以并存。
- `ask_user` 不再渲染成普通工具卡片（否则同一件事会出现两张卡片）。
- 卡片不引入新的运行时依赖，样式只用 `styles.css` 里的设计令牌（无字面色值）。
