# web-chat（增量）

本次变更只改「每轮预算的展示与修改」这部分，其余对话行为不变。

## API

- 设置 → 对话预算 读 `GET /api/chat/budget`，写 `PUT /api/chat/budget`（见 turn-budget 增量）。
- 面板不读 `GET /api/chat/models` 来拿预算：那一份只是同一解析结果的摘要，面板需要默认值与
  来源。两个接口的生效值同源，不会互相矛盾。

## 行为

- 面板显示**生效值**（一轮现在最多能跑多少），占位符显示**配置默认值**（恢复默认会回到哪里），
  每行一个来源标签（`config` → 「来自配置文件」，`console` → 「已覆盖」）。
- 保存后：面板重新渲染服务端返回的快照、清空错误、显示「已保存并立即生效：…」，并刷新模型目录
  （否则「对话」页仍显示旧的步数上限）。
- 校验错误逐字段显示在输入框下方（服务端的 400 也走同一个位置），不弹全局错误条。
- `恢复默认` 仅在存在覆盖时可点，清掉覆盖后三个维度都回到 `config.yaml`。
- `context.max_tokens = 0`（循环内压缩关闭）时，面板给出显式警告：调大步数会让每一步重发整段
  历史、token 成本近似平方增长，最终撞模型上下文上限；并指出另一半的修法（设置
  `context.max_tokens` 后重启）。压缩开启时改为一句话报告当前窗口大小。
